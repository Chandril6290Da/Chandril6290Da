# `03 / ENGINEERING PRINCIPLES`

- Understand the problem and the underlying concepts before choosing tools.
- Keep data cleaning and preprocessing steps reproducible.
- Select evaluation metrics that match the problem.
- Check for data leakage and avoid unsupported performance claims.
- Document project goals, setup steps, limitations, and future improvements.
- Consider responsible AI, fairness, and practical usability.

## My machine-learning workflow

```text
01. Define the problem
          ↓
02. Collect and understand the data
          ↓
03. Clean data and perform EDA
          ↓
04. Engineer features and preprocess
          ↓
05. Train models and tune parameters
          ↓
06. Evaluate results and analyse errors
          ↓
07. Integrate into an app or deployment workflow
          ↓
08. Monitor, document, and improve
```
